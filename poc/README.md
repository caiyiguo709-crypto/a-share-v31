# 免费备用行情源：独立、只观察 PoC

本目录不被正式行情采集、评分、网页或工作流调用。所有结果保存在被 Git 忽略的 `private/poc/`，研究许可和买入许可始终为 false。

## 范围和数据契约

- 原观察名单七只沪深主板股票；新浪与腾讯两个服务路径都实际取数，不把第一个非空结果作为通过。
- 日线为不复权 OHLC，成交量为股，成交额为人民币元。原始/SDK 数据与归一化数据分别保存。
- 新浪：使用 AKShare 1.19.1 的原始日线 URL 和解码器；验证响应变量与股票代码一致，直接解码，避免其日线包装函数的前向填充和去重。
- 腾讯：使用 AKShare 1.19.1 `stock_zh_a_hist_tx(adjust='')`。该版本把 `sz000` 股票误归入不转换成交量的指数前缀。在明确主板股票身份后，独立 PoC 对 `000` 股票把 SDK 成交量从手转换为股，记录乘数 100，原 SDK 数据不变。其他股票不重复转换。版本不匹配时拒绝取数。
- 腾讯保存的是 **SDK 输出**，不是原始 HTTP 响应；SDK 内部会排序、去重，尚不能验证被它丢弃的记录。新浪保存响应正文及解码记录。
- 分别记录服务提供方、采集时间、数据日期、接口、版本、异常类型链、HTTP 请求记录和失败阶段。错误记录不保存可能包含凭证的异常消息、完整请求参数或代理地址。
- 每个逻辑请求一次，PoC 无额外重试；每个工作进程最多 22 秒，最大两个并行进程。SDK 内部 HTTP 尝试总数标为未知，不能用一次逻辑请求冒充一次 HTTP 请求。
- 保留原代理与 TLS 设置，不改变系统网络设置。

## 验证方式

在项目根目录使用已审计的 Python 环境（Python 3.12.14、AKShare 1.19.1）：

```sh
PYTHONDONTWRITEBYTECODE=1 python -m pytest -q -p no:cacheprovider
PYTHONDONTWRITEBYTECODE=1 python -m poc.backup_sources --output private/poc/backup-sources.json
```

PoC 退出码 0 仅表示本次七组价格核验和金额/成交量单位合理性检查通过；不是系统验收或交易许可。退出码 2 表示有未通过或未运行项。交易日历不可用时，14 项股票请求全部不运行。

价格核验复用原有 `cross_check`，不改变其阈值。单位合理性另列：金额/股数应落在当日低高价格区间内，允许一分钱的发布舍入差。这是诊断规则，不是正式系统风险门槛，不会根据结果猜测并自动修复单位。测试数据仅用于离线故障注入。

未验证：两源指数、证券状态、除权除息、行业、资金流、云端网络、五个真实交易日的持续表现。服务路径不同也不能证明两家公司底层数据供应链完全独立。

不添加 Secrets、模型费用、推送、计划任务、公开 Pages 或交易功能。正式数据接口、评分、风控和持仓计算仍使用原代码；接入前须另行审阅和批准。

## Beta 0.1 手动云端诊断

2026-10-12 用户明确批准首次上传 `poc/free-backup-sources` 分支及一次手动 Actions 诊断。该分支的 `collect.yml` 保持仅 `workflow_dispatch`，运行 Ubuntu 24.04，凭证不保留在检出目录；不调用正式 build、Pages 或交易功能。

`python -m poc.cloud_report run` 分别新跑原 103 项测试、原 PoC 38 项测试、补充云端契约测试，再实际请求日历、七只股票的新浪/腾讯日线、三大指数的新浪/东方财富日线，共 21 个计划逻辑请求。原始结果留在忽略目录；仅脱敏的公共日线、质量结论、错误类型链、测试名称/结果和证据摘要输出到忽略目录 `beta01-artifacts/`，由工作流按文件白名单上传，保留三天。不能上传整个 private 目录或原始日志。

指数点位不能当作成分股平均成交价，因此不对指数套用股票的金额/量 VWAP 检查。东方财富指数文档明确成交量为手、成交额为元，转为股时记录乘数 100；新浪指数文档未承诺成交量单位，且未列成交额，相关项目保留 UNVERIFIED，不填补、不据此宣布完整通过。文档证据：[AKShare 指数说明](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)。

质量/测试失败让实际诊断及最终验收步骤非零退出；无论失败与否，后续报告和 Artifact 步骤使用 `always()`。初始化步骤预先生成 NOT_RUN 证据，只有初始化允许继续执行；正式测试与行情失败不允许继续作为通过。首次云端执行结束后停止，等待下一阶段授权，不自动重跑。
