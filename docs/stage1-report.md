## 风险与限制

1. 当前只能可靠验证部分免费接口，实时性与稳定性没有保证。必须先解决指数和证券状态元数据，再讨论开仓许可。
2. A/B/C与回踩规则是实验性启发式，尚未回测；行业/资金为null，总分为null。网页只展示技术小计/60，不能当作100分完整选股系统。
3. 采用未复权日线，除权和停牌可能触发保守阻断；第二阶段需复权一致性及当时股票池。
4. 费用是可配置模型，佣金和过户费在正式使用前需核验。50元只是含费用与滑点的计划损失，不能覆盖T+1、跳空、跌停造成的全部损失。
5. 每股测算相互独立；还没有组合账本、T+1模拟成交、实际账户门槛或历史回测，不应依据本阶段示例进行真实交易。
