## 限制与风险

1. 行业/资金代码完成，真实链路尚未贯通；完整评分正向流程仅在离线夹具验证。
2. 只有一个真实目标日归档，不能形成真实历史收益。45日演示人工价格/资金/行业/工作日日历包含真实假期，不能作为投资证据。
3. 日线无法证明盘口/排队成交。限价开盘和一字保守拒绝；T+1、停牌、跳空/跌停可导致超过50元损失。
4. 无分红/拆并股记账，因子变化窗口阻断；持仓质量缺失时收益留空。
5. 36小时规则使跨周末长假旧信号过期，需要开盘前重新采集。
6. 行业范围为自选所属，未全市场扫描，未实现可靠全市场历史股票池。
7. 本地锁支持macOS/Linux，Windows须WSL；免费接口在Actions的网络可用性未实测。
